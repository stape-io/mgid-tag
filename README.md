# Tapfiliate tag for Google Tag Manager Server Container

The **MGID tag** for Google Tag Manager Server Container lets you integrate MGID tracking with your server-side setup sending conversions, and customer records directly to the [MGID Postabck](https://help.mgid.com/postback-tracking-method).

## Installation

1. **Download the Template**: Download the `template.tpl` file from this repository.
2. **Import to GTM Server Container**: In **Templates** → **Tag Templates**, click **New**, then use the **three-dot menu** → **Import** to select the downloaded file.
3. **Create a New Tag**: Go to **Tags** → **New** and select the imported **MGID** template.
